# Python Assignment 2 - Data Structures

## Description

This assignment covers fundamental Python data structures and conditional statements. It demonstrates the creation, modification, access, and operations of Lists, Dictionaries, and Sets, along with Operators and IF, ELIF, and ELSE conditional statements.

## Topics Covered

- Lists
  - List creation
  - Append
  - Insert
  - Remove
  - Pop
  - Extend
  - Sorting
  - Maximum, minimum, and sum
  - Accessing list elements
  - List slicing
  - Reversing a list

- Dictionaries
  - Dictionary creation
  - Accessing values
  - Adding new key-value pairs
  - Updating values
  - keys()
  - values()
  - items()

- Sets
  - Set creation
  - Handling duplicate values
  - Set immutability
  - Union
  - Intersection

- Conditional Statements
  - IF
  - ELIF
  - ELSE
  - Performance category based on score
